# Tekken Clone – 3D Fighting Game

## Project Description

Tekken Clone is a 3D fighting game developed as part of the Game Design course project. The project is inspired by the Tekken fighting game series and focuses on implementing basic fighting mechanics, player interactions, opponent behaviour, and user interface elements.

The main objective of this project is to understand and apply 3D game development concepts using Unity and C#.

## Project Objectives

- Develop a 3D fighting game environment.
- Implement player fighting and attack mechanics.
- Control opponent behaviour during gameplay.
- Design an interactive user interface.
- Understand character control, animations, and game logic.

## Key Features

- 3D fighting game environment.
- Player fighting controller.
- Opponent controller.
- User interface for game interaction.
- Character fighting and attack mechanics.
- Multiple game maps and environments.

## Technologies Used

- **Game Engine:** Unity 6
- **Programming Language:** C#
- **Development Environment:** Visual Studio

## How to Open the Project

1. Clone or download this GitHub repository.
2. Install the compatible Unity 6 editor version.
3. Open Unity Hub.
4. Select **Add Project from Disk**.
5. Navigate to the `TekkenClone` folder.
6. Open the project and allow Unity to import the assets.
